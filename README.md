# 🚗 R-E Motors E-Commerce Website

An **e-commerce platform** for aftermarket car parts, built with **Node.js, Express, and Stripe** for seamless online transactions.

![R-E Motors Landing Page](R-E%20Motors%20Homepage.png)

## 🌟 Features

- 🛒 **Online Store** – Browse and purchase aftermarket car parts.
- 💳 **Stripe Integration** – Secure payments via Stripe.
- ⚡ **Express.js Backend** – Handles routing and payments efficiently.
- 🎨 **Bootstrap UI** – Responsive design for a seamless shopping experience.

## 📁 Project Structure

- 📦 R-E-Motors-E-Commerce-Website
-  ┣ 📂 public                # Static assets
-  ┣ 📂 views                 # EJS templates for rendering pages
-  ┣ 📜 server.js             # Express server & Stripe integration
-  ┣ 📜 package.json          # Project dependencies
-  ┣ 📜 items.json            # Product catalog
-  ┗ 📜 README.md             # Project documentation

## 🚀 Setup & Usage

### 1️⃣ Clone the Repository

`git clone https://github.com/RaghuRaikar/R-E-Motors-E-Commerce-Website.git`    
`cd R-E-Motors-E-Commerce-Website`

### 2️⃣ Install Dependencies

`npm install`

### 3️⃣ Set Up Environment Variables

Create a **.env** file and add your **Stripe API keys**:

`STRIPE_PRIVATE_KEY=your_private_key
STRIPE_PUBLIC_KEY=your_public_key`

### 4️⃣ Run the Application

`node server.js`

Open **`http://localhost:3000/store`** in your browser to start shopping!
